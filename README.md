# DoneZA - Your day, DoneZA.

DoneZA is an AI productivity hub built in South Africa. It helps professionals save time on emails, meetings, and daily planning with three smart workplace tools.

**Live app**: https://doneza-hub.lovable.app

## Tools

- **Smart Email Generator** — Create professional emails with recipient, purpose, key points, tone, and audience selectors.
- **Meeting Summarizer** — Turn long meeting transcripts into clear summaries, action items, and deadlines.
- **Task Planner** — Generate a prioritized daily schedule from 8am to 5pm.

# AI Productivity Hub

Build a modern, responsive web application called AI Workplace Productivity Assistant. Dashboard layout with sidebar navigation: Dashboard, Email Generator, Meeting Summarizer, Task Planner. Each feature has Input Section and Output Section with Copy/Edit buttons. Use Tailwind CSS, professional SaaS design. Implement 3 feature: 1) Smart Email Generator with To, Purpose, Key Points, Tone selector (formal, informal, persuasive), Audience selector (client, manager, team).  2) Meeting Summarizer with textarea and output showing Summary, Action Items, Deadlines. 3) Task Planner generating daily 8am-5pm schedule with priority tags. Add footer: "Responsible AI: AI-generated content, review before use." Publish ready.
